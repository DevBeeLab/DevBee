About

Building software, one real project at a time

I'm a software developer based in Oyo, Nigeria. My background spans Business Administration and, more recently, Computer Science at Ajayi Crowther University. That combination has shaped how I think about software: practically, with attention to detail, and with a focus on what the application actually needs to do.

I transitioned into software development through deliberate study and hands-on building. I work across the full stack: React, JavaScript and Tailwind CSS on the frontend; Python, Django and Django REST Framework on the backend; PostgreSQL for the database. I handle authentication, authorization and role-based access, and I deploy to Vercel, Render and GitHub Pages.

My flagship project, Shopoint RMS, is a full-stack retail management system live in production. It handles point of sale, inventory, customer management, suppliers, expenses, reports and multi-user access with store-level permissions. That project is the clearest demonstration of where I am as a developer right now.

I'm actively building my software development career and open to roles, freelance projects and collaborations involving modern web technologies.
